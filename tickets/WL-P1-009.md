# WL-P1-009: Add an owner inbox view of open gates and decisions

## Goal

All progress currently waits on the owner, and the open questions are spread over many ticket files. On 2026-11-09 no ticket is claimable for any tier, while eleven questions and several gates are open. Give the owner one command that lists what only they can unblock, ordered by how much work each answer releases.

## Context

- `scripts/tickets.py` already parses front matter and bodies; `availability()` computes why a ticket is not claimable.
- Open questions today: WL-P0-007C (six), WL-P0-007J (one), WL-P0-007K (one, in its Plan and Handoff rather than a Decisions section), WL-P0-009 (two), WL-P1-001 (one). Gates without approval that block otherwise-ready work: WL-P0-011, WL-P0-011A, WL-P0-016.
- Scope: `python3 scripts/tickets.py inbox`, read-only. It prints (1) tickets whose only blocker is the owner gate, (2) each numbered item under "Decisions needed" for `blocked` tickets, (3) for each, the count of tickets that transitively depend on it. Out of scope: recording answers; the owner still answers in conversation and an agent records the answer in the ticket.

## Acceptance criteria

- [ ] `inbox` on today's board lists the gates and decisions named in Context and nothing that is already approved.
- [ ] Each line shows the ticket ID, the question's first sentence, the recommendation if present, and the number of dependent tickets.
- [ ] Items are ordered by dependent count, largest first.
- [ ] Unit tests cover a gated-ready ticket, a blocked ticket with two decisions, and transitive counting.
- [ ] `tickets/README.md` lists the command in the script reference.
