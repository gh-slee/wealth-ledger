# UX-P2-008: Remove repeated headings and give report downloads descriptive names

## Goal

Screen-reader users hear several section names twice in a row, and the report reader offers downloads labelled only by file name. Small, but they make the analysis pages and the report page harder to scan.

## Context

### Current behaviour

- Observed on the synthetic browser fixture on 2026-11-10: on Holdings the headings are `H1 Holdings`, `H2 Holdings`, then the table caption "Holdings" (`frontend/src/components/analysis.tsx:249,290`).
- The same pattern: "Top 20 companies, including ETF holdings" (`analysis.tsx:392,397`), "Frozen ETF source dates" (`:401,404`), "Bitcoin & flows" (`:488,534`). Captions are visually hidden (`components/data-table.tsx:43`).
- Observed on the synthetic browser fixture on 2026-11-10: the report reader lists downloads as "portfolio.ods", "report.md", "report.pdf" (`frontend/src/components/report-reader.tsx:286,306`) and captions an attachment "01_account_values.png" (`:162`).

### Expected behaviour

- A table whose caption would repeat the heading directly above it is labelled by that heading with `aria-labelledby` instead.
- The panel heading under the page title says what the panel holds ("Positions", not "Holdings" again).
- Downloads read "Spreadsheet (ODS)", "Markdown", "PDF" with the file name as secondary text.

### Scope

- In scope: headings and captions in `analysis.tsx`; download and attachment labels in `report-reader.tsx`.
- Out of scope: table captions inside the saved report document ("Overview · 5"), which come from the frozen document.

### Implementation notes

- `DataTable` takes `caption: string` (`data-table.tsx:22`); add an optional `labelledBy` prop and keep the caption for callers without a heading.
- Browser tests locate some tables by caption text; update the locators, do not weaken assertions.

## Acceptance criteria

- [ ] On Holdings, Exposure and Bitcoin no heading text is immediately followed by an identical caption in the accessibility tree.
- [ ] Each table still has an accessible name.
- [ ] Report downloads show a format name and keep the file name visible.
- [ ] The automated accessibility checks in the browser suite pass in three locales.

### Tests

- Update locators in `frontend/tests/browser/workflow.spec.ts`, `country-exposure.spec.ts` and `report-reader.spec.ts`.

## Plan

- [ ] `labelledBy` on `DataTable`.
- [ ] Apply on analysis pages.
