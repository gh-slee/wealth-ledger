# WL-P0-007I: Serve the first page of an empty import review

## Goal

`read_preview_v1` refuses the first page of a review document that has no rows. The r7
`ReviewContent.rows` array has no minimum, so an empty review is valid, but the function
returns `import_stale` because its start position (0) is not below the row count (0).
The owner then cannot open the review at all. The first page should be empty with no
next cursor.

## Acceptance criteria

- [ ] With no cursor and zero rows, `read_preview_v1` returns `ok` with an empty `rows` array and a null `next`.
- [ ] A cursor positioned at or beyond the row count still returns `import_stale`.
- [ ] `test_review_read_preview_serves_an_empty_review_document` passes without `@unittest.expectedFailure`.
- [ ] Opt-in PostgreSQL suite and full suite pass; docs/web-v2-imports.md stays accurate.

## Plan

- [ ] Limit the `start_at>=total` refusal in `READ_PREVIEW_DDL` to requests that carry a cursor.
- [ ] Remove the expected-failure marker from the reviewer test.
- [ ] Run the PG and full suites; open the PR.
