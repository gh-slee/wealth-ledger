# WL-P0-007C: Add cleanup leases: claim_plan_v1 and cleanup_set_v1

## Goal

Let the worker claim terminal sets that still need cleanup and purge them through `_purge_v1`, even after the originating user session has expired.

## Context

## Acceptance criteria

- [ ] `claim_plan_v1(work_kind=cleanup)` selects deterministically and never double-claims.
- [ ] `cleanup_set_v1` purges via `_purge_v1`, records proofs and releases the reservation.
- [ ] Failed or pending cleanup keeps a retryable state and never drops proof.

## Plan

- [ ] Get owner answers to Decisions needed.
- [ ] Implement with fencing and proof tests.
- [ ] Run PG and full suites; open PR.

## Decisions needed

1. `leases.session_digest` is NOT NULL but cleanup has no user session. Options: (a) fixed cleanup-marker digest, (b) last user session that touched the set. Recommendation: (a).
2. `LeaseAck.source_fingerprint` for a cleanup lease, which has no source authority. Options: constant cleanup fingerprint, or the set digest. Recommendation: set digest.
3. Fence numbering for repeated cleanup attempts. Recommendation: 1 + number of earlier cleanup leases for that set.
4. Which child jobs `cleanup_proofs` must cover. Options: every normalize attempt that reached the launcher, or only the latest fence per member. Recommendation: every attempt that reached the launcher.
5. Pending/failed proof behaviour. Recommendation: keep `cleanup_state=failed` and hold the reservation until a proof succeeds.
6. Selection order. Recommendation: oldest terminal set with cleanup pending or failed and no live cleanup lease.
