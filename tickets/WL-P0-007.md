# WL-P0-007: Commit reconciled imports without permanent new CSV bytes

## Goal

Users upload a CSV, review a reconciled preview and confirm it. The V2 backend books facts, audit, generation
and outbox atomically, exactly once, and keeps no raw CSV bytes after normalization or cleanup. This epic is
split into child tickets so several agents can work in parallel where the files and contracts allow.

## Acceptance criteria

- [ ] AC-WL-P0-007-01: identical, overlapping, older, corrected and multi-account fixtures yield deterministic accepted heads.
