# WL-P1-014: Add CSV, JSON, PNG and ZIP exports to the V2 download panel

## Goal

The owner chose PDF, Excel, ODS and Markdown as the export formats for go-live on 2026-11-12. The data formats planned in WL-P0-013A's second delivery move here, so they do not hold up the release: CSV and JSON for the tables, PNG for each chart, and ZIP for everything at once.

## Context

### Current behaviour

- After WL-P0-013A, `POST /api/v2/exports` renders PDF, Excel, ODS and Markdown from a pinned calculation.
- The shipped application offers data exports from `frontend/src/components/report-exports.tsx` and `src/kurafolio/web/exports.py`.

### Expected behaviour

- The export service accepts `csv`, `json`, `png` and `zip`, from the same pinned calculation and with the same owner-only access.
- CSV escapes cells beginning with `=`, `+`, `-` or `@`. JSON keeps decimal values as strings.
- The download panel lists the new formats by name.

### Scope

- In scope: the four formats, panel entries, tests.
- Out of scope: scheduled exports, sharing links.

## Acceptance criteria

- [ ] Given a pinned calculation, then each new format matches the figures in the PDF of the same calculation.
- [ ] CSV formula escaping and JSON decimal strings are covered by tests.
- [ ] The ZIP contains every go-live format and the data formats, with a manifest naming the calculation.
- [ ] en-CA, zh-TW and zh-CN.

### Tests

- Extend the WL-P0-013A export tests and the WL-P0-013B panel spec.
