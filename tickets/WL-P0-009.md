## Goal

Versioned quote and FX adapters, manual and scheduled refresh with coalescing, a currency registry and immutable reference selection. Dependencies 003/004 are done, so this can run in parallel with WL-P0-007.

## Context

## Acceptance criteria

- [ ] A price-only refresh changes value/generation without a CSV or quantity change.
- [ ] CAD/USD/TWD and approved extra currencies reconcile the same fixed-rate oracle across APIs.
- [ ] A missing quote or FX rate gives a partial value, never zero or a complete-looking total.
- [ ] Manual and scheduled requests respect licensed delay and provider budget and expose actual as-of/check time.
