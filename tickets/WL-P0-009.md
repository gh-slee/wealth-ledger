# WL-P0-009: Refresh market quotes, FX and supported reporting currencies

## Goal

Versioned quote and FX adapters, manual and scheduled refresh with coalescing, a currency registry and immutable reference selection. Dependencies 003/004 are done, so this can run in parallel with WL-P0-007.

## Context

- The detailed draft spec is in the local planning package `docs/specs/wealth-ledger-v2/P0/WL-P0-009.md` until WL-P0-016 publishes it. If it is not in your checkout, work from this ticket and ask the owner.

### Owner decisions recorded 2026-11-10

- Display currencies: the user can convert to other popular currencies at the latest rate, beyond CAD, USD and TWD. Decision 2 below is answered: extra currencies are in scope. The list comes from what the chosen FX source covers.
- The app refreshes any stock, ETF or bond a user holds; no hard-coded symbol list.
- Value history is a daily line, so the contract needs historical daily prices and FX, not only the latest quote.
- Approach approved: a pluggable provider adapter. Bitcoin near real time from a public exchange API (the repository already uses Coinbase Exchange, `src/wealth_ledger/prices.py:88`). FX from an official daily source (already Bank of Canada Valet, `src/wealth_ledger/fx.py:12`) plus a keyless multi-currency daily source. Stocks, ETFs and bonds through an adapter the instance operator configures with their own API key; typically 15 minutes delayed or last close. Every value carries its "as of" time. A paid real-time provider can be added later without page changes.
- Provider choice is not made. First Plan step is a verification spike: for two or three candidate providers, fetch real quotes and daily history for Toronto-listed and US-listed ETFs and record coverage, delay, rate limits and licence terms from the providers' own pages. Secondary comparisons disagree on these figures and none confirmed Toronto coverage.
- Free tiers are generally licensed for personal use. An operator who opens an instance to the public must check the licence; say so in the operator guide.

## Acceptance criteria

- [ ] A price-only refresh changes value/generation without a CSV or quantity change.
- [ ] CAD/USD/TWD and approved extra currencies reconcile the same fixed-rate oracle across APIs.
- [ ] A missing quote or FX rate gives a partial value, never zero or a complete-looking total.
- [ ] Manual and scheduled requests respect licensed delay and provider budget and expose actual as-of/check time.
