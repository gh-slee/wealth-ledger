# UX-P1-015: Give the current shell a compact mobile navigation

## Goal

On a phone the shipped shell shows a full screen of navigation and settings before any content, and only three of nine destinations are visible in a sideways-scrolling row with no hint that more exist. A phone user should reach content on the first screen and find every destination.

## Context

### Current behaviour

- Observed on the synthetic browser fixture on 2026-11-10 at 375x812: brand, portfolio selector, a horizontally scrolling navigation row, "New portfolio", language, appearance and sign out stack above the page; `<main>` starts 380 px down and the Overview value 989 px down.
- Observed on the synthetic browser fixture on 2026-11-10: navigation links are 37 px tall and three of nine fit; the page does not scroll sideways.
- `frontend/src/styles.css:809-835` turns the sidebar into a static block and the nav into `display: flex; overflow-x: auto`.
- Sidebar markup is `frontend/src/App.tsx:371-428`.

### Expected behaviour

- At widths up to 700 px the shell shows one compact bar: brand, current page name and a menu button.
- The menu button opens a panel with all nine destinations, the portfolio selector, new portfolio, language, appearance and sign out. Choosing a destination closes it.
- Desktop layout is unchanged.

### Scope

- In scope: the shipped shell below 700 px.
- Out of scope: page content layout, the V2 shell (WL-P0-011A, which carries its own mobile criterion), balance privacy (UX-P2-003).

### Implementation notes

- `@radix-ui/react-dialog` is already a dependency and handles focus trapping and Escape; `imports.tsx:996-1030` shows its use.
- Targets must be at least 42 px high, the control height in [DESIGN.md](../DESIGN.md).
- Respect `prefers-reduced-motion` as the existing styles do (`styles.css:937`).

## Acceptance criteria

- [ ] Given 375x812, when any page loads, then `<main>` starts within the first 120 px.
- [ ] Given the menu is opened, then all nine destinations are visible without horizontal scrolling and each target is at least 42 px high.
- [ ] Given the menu is open, then focus moves into it, Tab stays inside, Escape closes it and focus returns to the menu button.
- [ ] Given a destination is chosen, then the menu closes and the page heading receives focus.
- [ ] Given 1024 px width, then the sidebar looks and behaves as before.
- [ ] Three locales, light and dark; no horizontal page scroll at 320 px.

### Tests
