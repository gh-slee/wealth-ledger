# UX-P1-010: Remember the interface language between visits

## Goal

The interface language returns to English on every page load, including the sign-in page. A reader of Traditional or Simplified Chinese must choose the language again after each reload. The appearance choice is already remembered; do the same for language and pick a first default from the browser.

## Context

### Current behaviour

- Observed on the synthetic browser fixture on 2026-11-10: after choosing Traditional Chinese on the sign-in page and reloading, the page is English, `document.documentElement.lang` is `en-CA` and `localStorage` is empty.
- `frontend/src/main.tsx:25` creates the locale with `useState<Locale>("en-CA")`.
- `frontend/src/lib/theme.tsx:24,47-48` stores and validates the appearance choice in `localStorage`.

### Expected behaviour

- The chosen language persists across reloads, sign-in and sign-out on the same browser.
- On first visit the language follows `navigator.languages`: Traditional Chinese variants map to `zh-TW`, other Chinese to `zh-CN`, everything else to `en-CA`.
- An invalid stored value is ignored and removed. If storage is unavailable the default applies silently.

### Scope

- In scope: one nonfinancial `localStorage` key; first-visit detection; validation.
- Out of scope: server-side preferences, new locales, the report language in portfolio settings.

### Implementation notes

- Copy the structure of `frontend/src/lib/theme.tsx`.
- Map `zh-TW`, `zh-HK`, `zh-MO` and `zh-Hant*` to `zh-TW`; other `zh*` to `zh-CN`.
- `docs/web-frontend.md` forbids persistent finance caches. Add one sentence there saying a language code is not financial data.

## Acceptance criteria

- [ ] Given the user selects Traditional Chinese on the sign-in page, when they reload, sign in or sign out, then the interface stays in Traditional Chinese.
- [ ] Given no stored choice and a browser whose first language is `zh-TW`, then the interface is Traditional Chinese; with `zh-SG` it is Simplified Chinese; with `fr-FR` it is English.
- [ ] Given a stored value that is not a supported locale, then the default applies and the value is removed.
- [ ] Given `localStorage` throws, then the app loads in the default language without an error.
- [ ] `document.documentElement.lang` always equals the active locale.

### Tests

- Unit tests in `frontend/tests/` for the mapping, the invalid value and the storage failure.
- Extend one browser test to reload after a language change.
