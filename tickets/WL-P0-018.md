# WL-P0-018: Make browser and dev-server test ports configurable for parallel agents

## Goal

Playwright uses a fixed `http://localhost:8765`, so two agents cannot run browser tests at once. Make the port come from an environment variable with the current default, and document it.

## Context

- `frontend/playwright.config.ts` (baseURL and webServer), [web-frontend.md](../docs/web-frontend.md).

## Acceptance criteria

- [x] `WEALTH_LEDGER_E2E_PORT` (default 8765) sets baseURL and the web server port.
- [x] Default behaviour and CI are unchanged.
- [x] Two runs on different ports pass at the same time.
- [x] docs/web-frontend.md and tickets/README.md mention the variable.

## Plan

- [x] Find the browser fixture, health check, and assertions that use the fixed port.
- [x] Read it from the environment.
- [x] Run two suites in parallel.
- [x] Update docs.
