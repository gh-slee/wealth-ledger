# WL-P0-018: Make browser and dev-server test ports configurable for parallel agents

## Goal

Playwright uses a fixed `http://localhost:8765`, so two agents cannot run browser tests at once. Make the port come from an environment variable with the current default, and document it.

## Context

- `frontend/playwright.config.ts` (baseURL and webServer), [web-frontend.md](../docs/web-frontend.md).

## Acceptance criteria

- [ ] `WEALTH_LEDGER_E2E_PORT` (default 8765) sets baseURL and the web server port.
- [ ] Default behaviour and CI are unchanged.
- [ ] Two runs on different ports pass at the same time.
- [ ] docs/web-frontend.md and tickets/README.md mention the variable.

## Plan

- [ ] Find every place the port is hard-coded (`grep -rn 8765 frontend scripts tests docs`).
- [ ] Read it from the environment.
- [ ] Run two suites in parallel.
- [ ] Update docs.
