# UX-P1-011: Fix the value chart time axis when there are few observations

## Goal

With one saved observation the "Value over recorded observations" chart prints eight repeated axis labels. Every new portfolio starts with one observation, so this is the first chart a new user sees and it looks broken.

## Context

### Current behaviour

- Observed on the synthetic browser fixture on 2026-11-10: on Overview and History with one observation the x axis reads "Jan 31, Feb 1, Feb 1, Feb 1, Feb 2, Feb 2, Feb 1, Jan 31".
- `frontend/src/components/chart-view.tsx:105-118` uses an ECharts `time` axis with a day-level formatter and `hideOverlap`. With one point ECharts picks sub-day ticks and the formatter collapses them to repeated day labels.
- The same component draws the chart on Overview (`analysis.tsx:112-130`) and History (`analysis.tsx:435`).

### Expected behaviour

- One observation: one labelled tick and one point.
- Two or more observations: each day label appears once, in order.
- Twelve monthly observations: unchanged from today.

### Scope

- In scope: axis ticks and labels of the value chart.
- Out of scope: colours, the data table alternative, the country exposure chart, payloads, the fixed time zone (WL-P1-007).

### Implementation notes

- A category axis for fewer than three points, or `minInterval` of one day with deduplicated labels, are both acceptable.
- Keep the tooltip formatter at `chart-view.tsx:96-103` working.

## Acceptance criteria

- [ ] Given one observation, then the x axis shows exactly one date label and one point.
- [ ] Given two observations on different days, then each day label appears once and in order.
- [ ] Given two observations on the same day, then labels are not repeated and both values are available in the tooltip and in "View chart data".
- [ ] Given twelve monthly observations, then the rendered labels equal those before the change.
- [ ] The label list is correct in en-CA and zh-TW.

### Tests

- A browser or unit test asserting the label list for one and two observations.
