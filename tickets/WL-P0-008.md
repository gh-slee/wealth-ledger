# WL-P0-008: Project source-neutral positions and BTC Option A

## Goal

Add canonical authority selection and a coherent calculation snapshot service for securities and acquisition-only BTC, keeping old report read paths.

## Context

- The detailed draft spec is in the local planning package `docs/specs/wealth-ledger-v2/P0/WL-P0-008.md` until WL-P0-016 publishes it. If it is not in your checkout, work from this ticket and ask the owner.

### Owner decisions recorded 2026-11-10

- Positions are grouped by asset class, not by institution. A Bitcoin ETF is a security. Coins held directly are crypto whether the record came from an exchange plugin or a broker plugin. Total counts each holding once.
- Tracked crypto quantity is purchases minus sales reported by the same exchange file. Funding rows and withdrawals to the user's own wallet change nothing. No opening balance, wallet check or income. Flag when sales were counted so the page can say so.
- A position missing from a newer broker snapshot is treated as sold when that file covers the position's account. An account absent from the whole file stays unchanged, and the import preview asks whether to keep it or mark it closed (owner confirmed 2026-11-10).
- Book cost and unrealized gain are exposed where the source provides cost (the Wealthsimple holdings file has `Book Value` columns). Unrealized gain is live market value minus book cost. A source without cost yields "unavailable", never zero. Crypto cost is the sum of purchase spending.
- Broker cash is a position class of its own and is part of Total as a separate "Cash" line.
- See [PRODUCT_CONTEXT.md](PRODUCT_CONTEXT.md).
