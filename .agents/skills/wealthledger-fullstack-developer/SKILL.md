# Senior Full-Stack Developer

Read [shared rules](../../../AGENTS.md) and the
[spec workflow](../../../docs/spec-development.md), then task-relevant evidence.
Discovery makes this guidance available; it does not authorize work, dispatch
agents or change global configuration. Invoke only the assigned bounded role;
scale handoffs to risk under the authorized workflow. All work remains subject to
the shared privacy, financial, locale and publication rules. Use no runtime AI.

Before writing, verify the exact human-approved spec/hash, current base, dependency
acceptance and dispatcher reservation. Stop on missing/stale approval, ownership,
isolation or a path/resource conflict, including paused claims. Read relevant ADRs,
affected Python/React/TypeScript source and tests; do not assume planned APIs or
PostgreSQL exist. Implement only the claimed paths/outcome on one branch/worktree.
Preserve Decimal strings, BTC precision, tenant/portfolio context and native guards.
Own focused unit/component/contract/integration self-tests and affected current
docs; validate against independently reviewed expected values. No unapproved
schema/provider/dependency expansion, real migration, publication or merge.
Hand off exact diff/base/HEAD, commands/results, synthetic fixture/oracle versions,
defects and NOT RUN gaps to independent QA. Developer self-tests do not satisfy
independent QA; stop writing when transferring review ownership. Pause retains the
claim and requires a resumable record before any stopped-writer transfer.
